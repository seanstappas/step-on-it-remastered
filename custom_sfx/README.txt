Custom sound overrides. Only used in custom-sound mode: press F6 in game or on the title menu
(or launch with `-- --custom-sfx`). F6 re-scans this folder, so new files need no restart.

Name a file <name>.wav, <name>.ogg or <name>.mp3 (WAV: 8/16/24-bit PCM or 32-bit float).
Any sound without a file here keeps its normal sound.

Blocks
  block_create          build a block (block keys)
  block_destroy         remove a block (block keys; also shots that smash blocks)
  block_crack           head-bonk, first hit (block cracks)
  block_break           head-bonk, second hit (block breaks)

Treasure / goodies
  coin                  silver coin
  coin_gold             gold coin
  coin_gem              gem
  coin_bars             gold bars
  pickup_key            coloured key
  exit_door             walking out the door (also the plain key goody)
  pickup_1up            1UP / extra life
  pickup_arrow_ammo     red-arrow ammo goody
  pickup_ball_ammo      bottled-swirl ammo goody
  pickup_time           time bonus
  pickup_multiplier     2x / 3x / 4x / 5x
  pickup_potion         shield potion
  pickup_shoes          speed shoes
  pickup_turtles        turtles (slow nasties)
  pickup_magnifier      magnifying glass
  pickup_thunderballs   thunderballs (defeat all nasties)
  teleport              transporter
  stop_go_switch        Stop/Go switch

Player
  shoot_arrow           fire the straight Magic Arrow
  throw_ball            throw the rolling Magic Ball
  player_die            player killed / falls in a pit
  hurry_up              Bonus drops to 1000

Nasties

  kill_hammer  kill_beanie  kill_walker  kill_teeth
  enemy_kill            any other nasty dies
